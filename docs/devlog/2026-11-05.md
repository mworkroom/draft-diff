# 2026-11-05 DraftDiff Development Log

## Work Summary

J님의 요청에 따라 Text Compare를 Before 입력·결과가 위쪽, After 입력·결과가 아래쪽에 오는 행 배치로 변경했다. 각 버전의 입력과 결과를 같은 행에서 확인하고, Before와 After를 위아래로 비교할 수 있다.

## Work Completed

- CSS Grid로 `Before | Before result`, `After | After result` 순서로 배치했다. 같은 행의 입력창·결과창 높이와 시작 위치를 맞췄다.
- 기존 글자 크기를 유지하고 긴 텍스트는 각 창 안에서 스크롤하도록 했다. 입력창 크기 조절로 두 행이 겹치지 않도록 수동 리사이즈는 비활성화했다.
- 650px 이하에서는 Before 입력 → Before 결과 → After 입력 → After 결과 순서로 세로 배치한다.
- 전체 자동 테스트 45개와 TypeScript·Vite 빌드가 통과했다.
- Browser 플러그인 스킬이 없어 기존 Playwright와 설치된 Chrome으로 빌드 결과를 검증했다. 100% 줌에서 2048×1152·1280×900 화면의 행 위치·창 높이·복사 버튼 접근성을 확인했고, 600px에서 세로 배치도 확인했다.
- 비교 결과 원문 보존, 양쪽 HTML·일반 텍스트 복사와 빨간색·들여쓰기 유지, Clear 후 입력 초점 복귀, Document Compare 진입을 확인했다. 페이지 가로 넘침·콘솔 오류·프레임워크 오류 화면은 없었다.

## Decisions

- 입력·결과의 DOM 순서와 비교·복사 로직은 유지하고 Text Compare 전용 CSS만 변경했다. 키보드 탐색 순서도 각 버전의 입력과 결과를 따라간다.
